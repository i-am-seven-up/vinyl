# L2 — Handoff player

## Luồng file

`AlbumsScreen` callback danh sách Song + index → `NowPlayingViewModel.playSongs` → `PlayerController` → MediaController → `PlaybackService` → ExoPlayer.

`AppContainer` nối controller/factory; `AppNavHost` giữ ViewModel dùng chung, mini player và route NowPlaying. Không gọi DAO từ UI.

- `player/PlaybackService.kt`: lifecycle player/session, audio attributes, session activity.
- `player/PlayerController.kt`: command, listener và PlaybackUiState top-level, MutableStateFlow private.
- `player/NowPlayingViewModel.kt`: bắt lỗi command và chuyển state; connection/release theo lifetime ViewModel.
- `player/NowPlayingScreen.kt`: UI nhận state/callback, Preview và effect poll theo lifecycle.
- `player/MiniPlayer.kt`: UI dùng chung giữa tab.

## API mở rộng UI / Queue

Tất cả command chạy main thread, trả Unit; lỗi validation/connection ném exception để ViewModel hiển thị. `playSongs(songs, startIndex)` thay toàn queue, prepare và phát; index phải hợp lệ. `playPause`, `next`, `previous`, `seekTo(positionMs)` điều khiển session. `playNext(song)` chèn sau current item; `addToQueue(song)` thêm cuối; `removeFromQueue(index)` xóa đúng occurrence, hỗ trợ cùng media ID nhiều lần. `setRepeatMode(mode)` nhận hằng Player.REPEAT_MODE_*, `setShuffle(enabled)` gán trạng thái.

`uiState` chỉ đọc, không tự scan hoặc phát. `playQueueItem(index)` phát một occurrence trong queue. `PlaybackUiState` (cùng file NowPlayingViewModel) có `queue: List<MediaItem>` snapshot và `currentIndex`. `QueueScreen.kt` dùng chung NowPlayingViewModel, mở từ NowPlaying; chọn/xóa theo index để hỗ trợ bài trùng. Album detail có menu Phát tiếp theo/Thêm vào hàng đợi. Danh sách hiện thứ tự timeline; shuffle có chú thích vì thứ tự phát có thể khác. Không lấy mutable MediaController/ExoPlayer trong Composable.

## Chạy thử

1. Theo README và L1 để có nhạc hợp pháp/content URI trên emulator API 32/36.
2. Cấp quyền audio → album → chạm một bài: phát toàn album từ bài chọn.
3. Mini player hiện tên bài/play-pause ở các tab; chạm tên để vào NowPlaying.
4. Thử seek, previous/next, repeat/shuffle; Home/khóa màn hình vẫn phát; notification/media button điều khiển được.
5. Vào app lại: cùng session/queue, không tạo player thứ hai. Pause rồi đóng UI để service được dọn theo Media3.

Quý bàn giao MVP Queue UI trong B2; Khánh cải thiện UI/UX theo các file trên. Chưa có kéo thả đổi thứ tự. B3 phụ trách fade/lịch sử/persist-resume; không hứa restore sau process death ở B2. File mất/quyền bị thu hồi báo playback error; chưa tự skip URI lỗi.

Tham chiếu: [Media3 background playback](https://developer.android.com/media/media3/session/background-playback), [Media3 1.8.0](https://developer.android.com/jetpack/androidx/releases/media3#1.8.0).
