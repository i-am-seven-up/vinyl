# Handoff L3 — Playlist và ghi dữ liệu

## Luồng file

- `shared/database/PlaylistDao.kt`: Playlist, PlaylistItem, PlaylistSong join và DAO. Item ID khác song URI để hỗ trợ bài trùng. Chỉ xóa occurrence theo item ID.
- `shared/database/VinylDatabase.kt`: schema v3, MIGRATION_2_3 tạo bảng/index/FK; AppContainer đăng ký cả 1→2 và 2→3.
- `shared/database/SongDao.kt`: replaceSongs giữ transaction, upsert rồi xóa URI không còn trong kết quả scan thành công. Không dùng REPLACE/delete toàn bảng vì FK cascade sẽ xóa playlist items.
- `playlist/PlaylistRepository.kt`: API dữ liệu cụ thể, chuyển lỗi FK thành thông báo bài/playlist mất.
- `playlist/PlaylistsViewModel.kt`: top-level UiState, theo dõi playlists/library/detail qua Flow; SavedStateHandle giữ selection. Command bắt lỗi, rethrow cancellation, expose read-only state và isSaving.
- `playlist/PlaylistsScreen.kt`: Route + Screen nhận state/callback, dialog tạo/rename/delete và picker, Preview. AppNavHost truyền callback player::playSongs dùng chung player B2/B3.

## API và mẫu để copy

Repository có observePlaylists/observeSongs/observeLibrary chỉ đọc. createPlaylist(id, name), renamePlaylist(id, name), deletePlaylist(id), addSong(id, uri), removeItem(id, itemId), moveItem(id, itemId, offset) là suspend Unit; không launch ngầm hoặc trả Boolean/ID. ViewModel tạo UUID trước create và chỉ chọn playlist sau khi command thành công.

DAO giữ validation tên và transaction ghi. addSong dùng position lớn nhất + 1; remove/move đánh lại position theo thứ tự. Xóa song bởi rescan cascade các occurrence của song đó; có thể để khoảng trống position cho tới thao tác remove/move, query luôn ORDER BY position, id. Không có unique constraint songUri vì bài trùng là hợp lệ.

Khánh dùng PlaylistsScreen làm điểm cải thiện layout, menu và drag/drop; giữ key item.id và truyền item.id khi remove/move. Không gọi DAO từ UI hoặc dùng song URI làm key occurrence. Tham khảo PlaylistsViewModel cho command lỗi/isSaving và PlaylistDaoDeviceTest cho transaction/rescan/migration.

## Chạy thử

1. Build/run, cấp quyền và scan nhạc ở Thư viện.
2. Playlist → Tạo playlist; tên chỉ khoảng trắng phải không lưu được.
3. Thêm hai bài, thêm lại bài đầu; dùng Lên/Xuống và Bỏ bài để kiểm tra đúng occurrence.
4. Phát tất cả hoặc chạm bài bất kỳ; mở NowPlaying/Queue xem đúng thứ tự và index.
5. Đổi tên, đóng/mở app: playlist và thứ tự còn nguyên. Rescan cùng thư viện không mất items.
6. Xóa file rồi rescan: bỏ đúng bài đã mất. Xóa playlist có xác nhận và không xóa file nhạc.

Chi tiết kết quả và giới hạn ở [B4 TESTING](../b4/TESTING.md). UI thô được bàn giao để Khánh hoàn thiện; B5 tiếp tục search/settings, chưa mở thêm màn History/Stats.
